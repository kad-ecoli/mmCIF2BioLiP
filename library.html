The template library files for protien function prediction by COACH and COFACTOR.


TM-SITE library

  • pocket.tar.bz2 (template binding pocket structure files)
  • BSITES.bsr (binding site residues)
  • BSITES.fasta (template fasta sequences)
  • BSITES.center (coordinates of binding pocket centers)

    S-SITE library

  • PSSM.tar.bz2 (emplate sequence profiles with binding site information)
  • BSITES.bsr (binding site residues)
  • BSITES.fasta (template fasta sequences)
  • BSITES.fpt (template ligand fingerprints)

    COFACTOR library

  • receptor.tar.bz2 (receptor structure files)
  • ligand.tar.bz2 (ligand structure files)
  • Enzyme.tar.bz2 (EC library files)
  • GO.tar.bz2 (GO library files)
  • map.tar.bz2 (the mapping between ligand-binding, EC and GO templates)
    • Reference:
    Jianyi Yang, Ambrish Roy, and Yang Zhang. BioLiP: a semi-manually curated database for biologically relevant ligand-protein interactions, Nucleic Acids Research, 41: D1096-D1103 (2013) (download the PDF file).
